## Tesla Static Website Clone

A static clone of the Tesla landing page built using HTML5 and CSS3 as part of my web design learning journey.
This project focuses on layout design, visual styling, and UI structure, inspired by Tesla’s official website.

## Live Demo: https://shabeehak.github.io/Tesla-Static-Website/

## Preview

- A clean and minimal Tesla-inspired landing page featuring:
- Hero sections with background imagery
- Modern typography and spacing
- Section-based layout
- Static UI design

## Project Overview
This project was created to practice static web layout design and understand how modern product websites structure content visually.
It is a non-responsive, frontend-only project, built purely for learning and UI practice.

## Technologies Used

- HTML5 – Semantic markup
- CSS3 – Layout, positioning, and styling
- GitHub Pages – Hosting

## Features

- Tesla-inspired minimalist UI
- Clean and structured layout
- Static webpage implementation
- Focus on typography and spacing
- Organized and readable code

## What I Learned

- Structuring sections for modern landing pages
- Using CSS for positioning and layout
- Applying visual hierarchy and spacing
- Building static UI clones from real-world designs
- Hosting static websites with GitHub Pages

## Learning Context

This project was built as part of my frontend and web design learning journey.
The main objective was to practice UI structure and visual styling, not responsiveness or backend functionality.
